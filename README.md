# Kubernetes Labs

Repositório destinado a documentar minha evolução prática no estudo de **Docker, conteinerização e Kubernetes**.

O objetivo não é apenas registrar comandos, mas entender os conceitos envolvidos, executar laboratórios e documentar problemas e soluções encontrados durante o aprendizado.

Desenvolver conhecimento prático em orquestração de containers e compreender como essas tecnologias são utilizadas na arquitetura e operação de aplicações modernas.
